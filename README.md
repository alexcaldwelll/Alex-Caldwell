# Alexandra — Personal Website

A personal website and blog built around a cinematic, scroll-driven story: a consistent yellow pencil represents Alexandra, drawing a road and memories that gradually become colorful 3D scenes. The journey moves through Seattle, Charleston, Washington, DC, Nashville, and an intentionally unfinished future.

The site has two destinations:
- **Home** — the cinematic journey (desktop) and a static vertical journey (mobile/reduced motion).
- **Blog** — a calm, Markdown-powered writing space.

Faith and love are recurring themes, represented by a subtle golden light that remains with the pencil from the Washington, DC chapter onward.
