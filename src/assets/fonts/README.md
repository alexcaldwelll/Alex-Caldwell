# Typography provenance

Titles use the locally installed Georgia (Times New Roman/serif fallback), a quiet editorial serif. Navigation and body copy use the platform system sans: Apple system / BlinkMacSystemFont on macOS/iOS, Segoe UI on Windows, Arial/sans-serif fallback elsewhere.

These are legitimate system-font references; no font binaries are copied, downloaded, redistributed, or fetched from a third party. The fonts remain licensed by the user's operating system and its vendors. This avoids an external font request and font-swap layout changes. Appearance varies slightly with platform; readable measure and spacing do not depend on one vendor's metrics.
